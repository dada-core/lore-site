---
title: "Raccourcis clavier"
description: "Lore se pilote au clavier : recherche, import, panneaux et fenêtres."
---

## Dans l’application

| Raccourci | Action |
| --- | --- |
| <kbd>Ctrl K</kbd> | Rechercher ou aller à une page, un espace, un document |
| <kbd>/</kbd> | Ouvrir la recherche |
| <kbd>I</kbd> | Importer des documents |
| <kbd>[</kbd> | Afficher ou masquer la barre latérale |
| <kbd>]</kbd> | Afficher ou masquer le panneau de droite |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Entrée</kbd> | Parcourir et ouvrir un résultat |
| <kbd>Échap</kbd> | Fermer une fenêtre ou un menu |
| <kbd>Ctrl Entrée</kbd> | Envoyer une question à l’assistant <span class="vb">v0.3</span> |

Sur macOS, <kbd>Ctrl</kbd> est remplacé par <kbd>⌘</kbd>.

## Dans cette documentation

| Raccourci | Action |
| --- | --- |
| <kbd>Ctrl K</kbd> ou <kbd>/</kbd> | Rechercher dans la documentation |
| <kbd>[</kbd> | Afficher ou masquer le menu de la documentation |
| <kbd>]</kbd> | Afficher ou masquer le sommaire de la page |
