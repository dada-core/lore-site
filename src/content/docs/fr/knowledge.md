## Contenu d’une fiche

| Champ | Contenu |
| --- | --- |
| Problème ou question | Ce que l’on cherche à résoudre. |
| Contexte | Système concerné, environnement, circonstances. |
| Symptômes | Ce que l’on observe : messages d’erreur, comportements. |
| Causes | Ce qui provoque le problème. |
| Solution | Les étapes appliquées. |
| Précautions | Ce qu’il faut vérifier ou éviter. |
| Ressources associées | Les documents sources : runbooks, rapports d’incident… |

## Cycle de validation

Une fiche passe de *Brouillon* à *En attente de validation*, puis à *Validée* lorsqu’un responsable de l’espace l’approuve. Seules les fiches validées sont proposées en priorité dans la recherche.

## Créer une fiche

- Depuis la base de connaissances, avec *Nouvelle fiche*.
- Depuis un document, par exemple un rapport d’incident.
- Depuis une réponse de l’assistant <span class="vb">v0.3</span> : la fiche est pré-remplie et doit être relue.
