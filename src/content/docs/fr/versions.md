## Versions

Chaque import d’un fichier crée une nouvelle version. Les versions précédentes restent consultables et téléchargeables. Dans le panneau de droite, l’historique est dessiné en strates : la plus récente en haut, l’épaisseur indiquant l’ampleur des modifications.

## Statuts

| Statut | Signification |
| --- | --- |
| Brouillon | Visible par les membres de l’espace, signalé comme non finalisé. |
| En attente de validation <span class="vb">v0.2</span> | Soumis aux responsables de l’espace avant publication. |
| Publié | La version de référence. |
| Obsolète | Reste consultable et cherchable, classé en dernier, avec son remplaçant. L’assistant ne l’utilise jamais. |
| Archivé | Retiré des listes et de la recherche, consultable par les responsables. |

## Marquer un document comme obsolète

Choisissez *Changer le statut › Obsolète* et indiquez, si possible, le document qui le remplace. Un bandeau oriente alors les lecteurs vers la bonne procédure.

## Dates de révision <span class="vb">v0.2</span>

Une date de révision prévue rappellera au responsable de relire le document. Les révisions en retard apparaîtront dans le tableau de bord.
