## Versions

Each import of a file creates a new version. Previous versions remain available to read and download. In the right panel, the history is drawn as strata: the most recent on top, the thickness showing how much changed.

## Statuses

| Status | Meaning |
| --- | --- |
| Draft | Visible to the space members, flagged as unfinished. |
| Awaiting review <span class="vb">v0.2</span> | Submitted to the space owners before publication. |
| Published | The reference version. |
| Outdated | Still readable and searchable, ranked last, with the document that replaces it. The assistant never uses it. |
| Archived | Removed from lists and search, readable by the space owners. |

## Mark a document as outdated

Choose *Change status › Outdated* and, if possible, the document that replaces it. A banner then points readers to the right procedure.

## Review dates <span class="vb">v0.2</span>

A planned review date will remind the owner to read the document again. Overdue reviews will appear in the dashboard.
