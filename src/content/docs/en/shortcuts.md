## In the application

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl K</kbd> | Search, or go to a page, a space, a document |
| <kbd>/</kbd> | Open search |
| <kbd>I</kbd> | Import documents |
| <kbd>[</kbd> | Show or hide the sidebar |
| <kbd>]</kbd> | Show or hide the right panel |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> | Move through results and open one |
| <kbd>Esc</kbd> | Close a window or a menu |
| <kbd>Ctrl Enter</kbd> | Send a question to the assistant <span class="vb">v0.3</span> |

On macOS, <kbd>Ctrl</kbd> is replaced by <kbd>⌘</kbd>.

## In the PDF viewer

Once the viewer is selected, with a click or with <kbd>Tab</kbd>:

| Shortcut | Action |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Previous page, next page |
| <kbd>+</kbd> <kbd>-</kbd> | Zoom in, zoom out |

These keys do nothing while you type. In a Markdown, Word or text document, <kbd>Ctrl F</kbd> searches the content shown, and <kbd>Ctrl P</kbd> prints it. See [Reading a document](reader.md#the-pdf-viewer).
