## In the application

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl K</kbd> | Open the palette: search, or go to a page, a space, a document |
| <kbd>/</kbd> | Open the Search page, with its field selected |
| <kbd>I</kbd> | Import documents, where you can import |
| <kbd>[</kbd> | Show or hide the sidebar |
| <kbd>]</kbd> | Show or hide the right panel, on a document’s page |
| <kbd>Esc</kbd> | Close a window or a menu |
| <kbd>Ctrl Enter</kbd> | Send a question to the assistant <span class="vb">v0.3</span> |

On macOS, <kbd>Ctrl</kbd> is replaced by <kbd>⌘</kbd>. These shortcuts, except <kbd>Esc</kbd> and <kbd>Ctrl Enter</kbd>, do nothing while you type or while a window is open.

## In the palette

| Shortcut | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Choose an item |
| <kbd>Enter</kbd> | Open the item chosen: the first one, “Search the documents for “…””, runs the search |
| <kbd>Esc</kbd> | Close the palette |

See [The palette](search.md#the-palette).

## In the version history

Once a band of *Versions* is selected, with a click or with <kbd>Tab</kbd>:

| Shortcut | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Later version, earlier version |

See [History in strata](versions.md#history-in-strata).

## In the PDF viewer

Once the viewer is selected, with a click or with <kbd>Tab</kbd>:

| Shortcut | Action |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Previous page, next page |
| <kbd>+</kbd> <kbd>-</kbd> | Zoom in, zoom out |
| <kbd>=</kbd> | Zoom in, like <kbd>+</kbd> |

These keys do nothing while you type. In a Markdown, Word or text document, <kbd>Ctrl F</kbd> searches the content shown, and <kbd>Ctrl P</kbd> prints it. See [Reading a document](reader.md#the-pdf-viewer).
